# Python Learning Journey

A collection of Python exercises and coursework spanning 2018–2025, tracking my progression from language fundamentals through data science and machine learning basics. Commit dates reflect the original file modification dates, not the date this repo was published.

## What's here
- **Fundamentals** — `Basics/`, `Arrays/`, `Sets/`, `Strings/`, `For/`, `While/`, `Functions/`, `Objects/`, `Week1`–`Week5`, `Exercises/`
- **OOP** — `Classes/` (incl. `BankAccount.py`, a simple account class with deposit/withdraw validation)
- **File I/O** — `File/`, `Dictionary/`
- **GUI** — `GUI/` and `Common/GUI/` (Tkinter), `Kivy/` (Kivy basics)
- **Data science** — `Jupyter/` (pandas, data cleaning, stats — based on a Coursera data science with Python course)
- **Machine learning** — `kaggle/introToMachineLearning/` (Kaggle's Intro to ML micro-course, incl. the Moneyball exercise)
- **Games** — `games/` — small standalone scripts (quiz games, a word-guessing game, turtle graphics, Caesar cipher)
- **Web (Flask)** — `Flask/HelloApp/` (minimal Flask app), plus Flask bootcamp work from 2023:
  - `Flask/Tutorial/` — routing, Jinja templates and inheritance, WTForms, flash messages, and `userAuth/` (login/registration with Flask-Login, Google OAuth demo)
  - `Flask/Databases/` — Flask-SQLAlchemy CRUD and a puppy adoption site with Flask-Migrate
  - `Flask/flaskAPI/` — a small REST API with JWT authentication
  - `Flask/stripe/` — a Stripe Checkout donation page (Stripe's public test key only)
  - `Flask/Deployment/` — minimal app prepared for deployment
- `spiderman.sb2` — an early Scratch project

## Note on data
Third-party datasets and course-provided files (Coursera saved pages, PDFs, large CSVs like NISPUF17/census/listings) were excluded — this repo is the code, not redistributed course material.
